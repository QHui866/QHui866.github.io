# Academic Homepage

Static academic homepage for Qian Hui. Add a portrait later if desired by replacing the initials card in `index.html`.

## 发布到 GitHub Pages

1. Create a public repository named `QHui866.github.io`.
2. Upload all files in this folder, including `assets/hero-campus.png`.
3. In Settings → Pages, deploy from the root of the `main` branch.

The published site will be available at `https://qhui866.github.io/`.
